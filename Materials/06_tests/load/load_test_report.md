# Отчёт о нагрузочном тестировании (подраздел 7.3)

## 1. Условия проведения испытания
* **СУБД:** SQLite 3 (`toll.db`, 9 нормализованных таблиц).
* **Инструментарий:** DB Browser for SQLite, Диспетчер задач Windows, отладчик Microsoft Visual Studio 2022.
* **Объём тестовой выборки:** 1 003 записи в таблице проездов `Trip` (3 базовые записи + 1 000 сгенерированных через рекурсивное CTE `WITH RECURSIVE`).

## 2. Результаты замеров производительности

| Метрика / Операция | Измеренное значение | Норматив | Статус |
| :--- | :---: | :---: | :---: |
| Пакетная вставка 1 000 записей (`INSERT ... WITH RECURSIVE`) | **11 мс** | ≤ 500 мс | Пройдено |
| Агрегирующая выборка (`COUNT`, `SUM`, `AVG`, `GROUP BY`) по 1 003 строкам | **15 мс** | ≤ 200 мс | Пройдено |
| Нагрузка на центральный процессор (`POSINV.exe`, режим ожидания/навигации) | **0,2 %** | ≤ 15 % | Пройдено |
| Потребление оперативной памяти (`POSINV.exe`, Working Set) | **22,7 МБ** | ≤ 150 МБ | Пройдено |
| Итоговая выручка по контрольному набору (`TotalRevenue`) | **299 535,00 руб.** | — | Корректно |
| Средний чек по выборке (`AvgCheck`) | **298,64 руб.** | — | Корректно |

## 3. Выявленные особенности при работе под нагрузкой и интеграции
* На уровне СУБД SQLite обработка 1 000+ записей выполняется за **11–15 мс** без деградации времени отклика и блокировок файла БД.
* При обращении клиентского модуля `POSINV.exe` (`SQLiteDataAccess.LoadProducts`) к унаследованным полям шаблона с типом `REAL`/`Double` зафиксировано исключение приведения типов Dapper (`System.OverflowException: Error parsing column 1 (CostPrice) — Значение было недопустимо малым или недопустимо большим для Decimal`), что внесено в перечень дефектов для перевода маппинга моделей на новую схему `Tariff`/`Trip`.
