# 7.4. Журнал выявленных дефектов (Bug Report)

В ходе функционального (7.1) и нагрузочного (7.3) тестирования информационной системы учёта проезда по платным дорогам зарегистрированы следующие дефекты и несоответствия:

| ID | Модуль / Экран | Описание дефекта | Шаги воспроизведения | Критичность | Статус | Подтверждение |
| :--- | :--- | :--- | :--- | :---: | :---: | :--- |
| **BUG-01** | `SQLiteDataAccess.cs` (`LoadProducts`) | Исключение `System.OverflowException`: ошибка приведения значения столбца `CostPrice` (`Double` / `REAL`) к типу `Decimal` в Dapper при загрузке каталога. | 1. Запустить `POSINV.exe`.<br>2. Перейти в раздел расчёта/продаж.<br>3. Вызвать загрузку списка позиций. | Высокая (Critical) | Открыт (в план рефакторинга) | `load/S20_vs_decimal_overflow.png` |
| **BUG-02** | Вкладка «ДОБАВИТЬ ТАРИФ» | Отсутствует проверка нижней границы числового ввода: система допускает ввод отрицательного значения тарифа (`-10`). | 1. Открыть «Управление тарифами и дорогами» → «ДОБАВИТЬ ТАРИФ».<br>2. Ввести `-10` в поле стоимости. | Средняя (Major) | Открыт | `S09_tc05.png` |
| **BUG-03** | Главное меню / Вкладки справочников | Не настроено скрытие административных вкладок («МАГИСТРАЛИ», «КЛАССЫ ТС») для учётной записи с ролью рядового оператора ПВП. | 1.
